# Company Social Media Manager

A lightweight single-page web app for managing a company's social media presence from a browser.

## Features
- Track connected social media accounts by platform and handle.
- Compose and schedule posts or save them as drafts.
- View a simple content calendar queue.
- See a performance snapshot with high-level metrics.
- Get live hashtag and copy suggestions while drafting posts.

## Run locally
Open `index.html` in your browser.

Optional local server:
```bash
python3 -m http.server 4173
```
Then visit `http://localhost:4173`.
